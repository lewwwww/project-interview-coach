## 什么是 BEI / STAR

**BEI（Behavior Event Interview）行为事件面试**：通过追问候选人过去真实行为来预测未来表现。

**STAR 法则**（回答框架）：
- **S**ituation — 背景：当时的情境是什么？
- **T**ask — 任务：你的职责/目标是什么？
- **A**ction — 行动：你具体做了什么？
- **R**esult — 结果：最终结果/数据/影响是什么？

## 用户核心故事模块（宝洁八大问拆解）

> 底层逻辑：用宝洁八大问拆解用户过往经历，沉淀三类可直接调用的核心故事模块。面试遇行为类追问，直接调取对应模块作答，不临场卡壳。**素材不足就补一个真实小事，不编造。**

**① 高目标与执行力**——"主动设定高难度目标，最终落地完成"
- 适合被问：最成功的事
- 关键词：目标明确、统筹协调、按时交付
- 素材池（用户简历真实素材）：蓝桥杯 Java 省二 / 数学建模省二备赛；实习独立完成业务模块

**② 领导力与说服力**——"带领团队推进项目，或说服持不同意见的合作方达成共识"
- 适合被问：团队协作
- 关键词：倾听、沟通、求同存异
- 素材池：担任学生干部/组织负责人——组织活动、协调多方（如校企对接）

**③ 创新与困境应对**——"项目遇到突发卡点，拆解问题、找到解法最终解决"
- 适合被问：最遗憾的事/最大困难
- 关键词：定位、拆解、复盘
- 素材池：实习联调排错 / 毕设项目卡点 / 搭建 RAG/Agent 项目时遇到的坑

**示例（挑战性任务）**：
S：一个月内策划校级活动（通常需两个月），时间极紧。
T：统筹多部门，在截止日前高质量完成。
A：用 5W1H 明确主题目标 → 拆解任务分工到人 → 每周例会同步 → 活动前一天现场逐项确认。
R：活动顺利举行，节省 10% 预算，参与方满意。

**示例（失败经历）**：
S：周末促销兼职，目标 150 瓶；T：负责展台销售。
A（反思）：前期被动等人咨询，结束后主动请教负责人，学到主动出击、耐心讲解、挖掘需求三点。
R：虽只卖出 32 瓶，但深刻理解主动性，后续做事更主动。

## 央国企 / 银行行为题库（高频，来自笔记库）

> ⚠️ **本表是提炼版框架**：出题前先实时读取笔记库 `行为题素材.md` 原文，**题库与话术以笔记库最新内容为准**；本表用于快速定位题与考察点。

### 半结构化高频问题（15 题，出题与评估用）

| # | 题目 | 考察点 | 答题要点 |
|---|---|---|---|
| 1 | 为什么来应聘这个岗位/公司？ | 求职动机、非海投 | 公司角度（业务+培养）→ 个人角度（技能匹配）→ 家庭/意愿（本地/家乡）；一句岗位职责概括 + 1-2 匹配点 + 非海投证据 |
| 2 | 你没有相关工作经验，我们为什么录用你？ | 短板态度、潜质 | 承认差距 → 拆解岗位真正看重什么 → 可迁移能力+证据 → 前置准备 → 成长承诺 |
| 3 | 你的优缺点是什么？ | 自我认知 | 优点：性格品质层 + 实例 + 贴岗位；缺点：技能层不贴人格标签 + 改进行动 + 已生效 |
| 4 | 你的职业规划？ | 留得住、值得培养 | 短期(1年)熟悉业务转职场人 → 中期(2-3年)独立负责中型项目 → 长期(4-5年)带团队复合型 |
| 5 | 能接受加班吗？ | 敬业度 | 先反思效率 → 理解项目节点需要 → 有心理准备+过往实例 → 日常合理安排 |
| 6 | 工作枯燥重复，你能接受吗？ | 沉得下心 | 能接受；基础工作是熟悉业务的机会；讲重复中总结方法提效的真实例子 |
| 7 | 能接受岗位调剂/偏远地区/轮岗吗？ | 服从性、稳定性 | 思想上接受 → 价值转换（轮岗对成长的好处）→ 行动承诺；有地域底线先不主动提 |
| 8 | 你的期望薪资？ | 议价姿态 | 尊重公司应届生薪资体系 → 更看重成长 → 按校招标准；不漫天要价也不卑微 |
| 9 | 你还有什么想问的？ | 主动性 | 问岗位最重要能力/培养体系/团队发展；不问薪酬福利细节、加班、双休 |
| 10 | 为什么没有参加秋招？ | 动机真实 | 曾准备考研 → 认清更适合实践 → 转就业后系统补强技术栈+实习 → 目标明确（绝口不提备考公职） |
| 11 | 跟有实践经历的同学比，你有什么优势？ | 自信、差异化 | 实习独立负责业务模块 + 毕设/微服务全流程落地 + 竞赛高压稳定输出 |
| 12 | 为什么从上家公司离职？ | 稳定性 | 应届生用"职业方向匹配"框架，不抱怨原单位，落脚主动选择、方向清晰 |
| 13 | 你对我们岗位了解多少？ | 用心程度 | 一句话职责概括（看岗位材料）+ 岗位要求拆解 + 匹配证据 |
| 14 | 空窗期都在做些什么？ | 真实性 | 空窗期=主动学习+求职准备+项目沉淀，用完成度证明没荒废 |
| 15 | 你为什么适合这个岗位？ | 匹配度 | 能力匹配（技术栈+项目证据）+ 意愿（地域+长期发展），落脚踏实做下去 |

### 行为面试其他常见问题（13 题）

| 题目 | 考察点 | 参考回答方向 |
|---|---|---|
| 工作中与上级意见不一致 | 沟通力、服从性 | 先倾听 → 表达观点 → 沟通 → 服从最终决策 |
| 手头多项任务节点接近 | 优先级管理 | 按轻重缓急排序，拆分碎片时间 |
| 如何适应新环境/新角色 | 学习力 | 主动请教 → 梳理流程 → 快速上手 → 反思总结 |
| 你如何看待压力 | 抗压性 | 适度压力激发动力，过高压力自我调节 |
| 你在选择工作中看重什么 | 求职动机 | 平台前景 → 团队氛围 → 学习机会 → 薪资保障 |
| 你期望的工作环境 | 文化匹配 | 坦诚沟通、互帮互助、共同进步 |
| 你还有在面其他公司吗 | 竞争力 | 有 offer 但看重贵公司，正全力准备此次面试 |
| 开发相关知识是如何学习的 | 学习力 | 课程打底 → 项目实战 → 开源/博客持续补 |
| 对于工作地点如何考虑 | 意愿 | 结合岗位说明（如家乡所在省份优先，具体按实际） |
| 实习有没有达到你的预期 | 真实性 | 如实讲收获，落脚"更确定方向" |
| 你的爱好 | 个性/稳定性 | 选能体现学习力/耐心的爱好（羽毛球/民族舞/跑步） |
| 想做技术还是业务 | 意愿 | 技术为主，结合岗位可兼顾业务 |
| 老家哪的/是否独生子/家人支持吗 | 稳定性 | 如实答，落脚"家人支持、能稳定投入工作" |

> 出题原则：行为题**必须能落回用户真实经历**（实习/毕设/项目/学生工作等），用行为题素材的题库 + 最新版简历的素材池出题；简历里没有的经历不拿来问。用户答完按追问逻辑深挖。

## BEI 题追问逻辑

当用户在互动模式回答了 BEI 题时，按以下逻辑追问：

1. **S/T 不清楚** → 「当时背景能说清楚一些吗？这是在什么公司/团队/阶段？」
2. **A 不具体** → 「你具体做了什么？是你主导还是和其他人一起？」
3. **R 没数据** → 「最终结果如何？有没有可以量化的指标？」
4. **全用「我们」** → 「你在这件事里个人贡献了什么？」
5. **回答过于完美** → 「这件事有没有什么遗憾或者你觉得没做好的地方？」

## 评分维度（互动追问模式使用）

在模拟面试互动模式中，对用户回答的评估维度：

| 维度 | 优秀表现 | 不足表现 |
|------|---------|---------|
| 结构性 | STAR 完整，逻辑清晰 | 散乱，跳跃 |
| 具体性 | 有数字、名字、时间 | 全是模糊表达 |
| 影响力 | 结果有业务影响 | 结果不清晰 |
| 个人贡献 | 「我」字明确 | 「我们」模糊化 |
| 反思深度 | 有总结和教训 | 只说结果 |
