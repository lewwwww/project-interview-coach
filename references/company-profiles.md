# 公司画像：面试风格 · 筛选标准 · 流程

> 阶段 4 调用：按目标公司匹配面试文化与考察重点。本 skill 面向**央国企 / 银行 / 事业单位 / AI 应用岗 / 后端校招**，大厂表精简保留。

---

## 通用简历筛选逻辑（央国企 HR 初筛）

央国企/银行 HR 初筛关注顺序（通常 1-2 分钟内）：

1. **学历** — 双一流/一本/二本分层；部分岗位卡「双一流」门槛
2. **政治面貌** — 党员/预备党员显著加分（党建岗/公务员岗可能是硬条件）
3. **专业匹配** — 专业名称与岗位目录是否对得上（计算机/软件 vs 信息科技岗）
4. **稳定性信号** — 籍贯属地（本地/邻近省份优先）、求职意向一致性
5. **项目/实习相关性** — 有量化数字（QPS/功能数/并发）的比没数字的强
6. **形式规范** — 一页纸、无错别字、格式统一；材料题（公文/申论）看写作功底

**注意**：央国企不看跳槽频率（校招无此问题），更看重「能不能长期稳定服务」与「综合素质」。

## 央国企

### 税务系统 / 金融监管（国考岗位）

| 维度 | 内容 |
|---|---|
| 流程 | 笔试（行测+申论）→ 结构化面试（多数）→ 体检政审 |
| 面试风格 | 结构化：重条理、重逻辑、重动机真实；无技术深挖（科技岗除外） |
| 高频题 | 为什么考税务/金融监管？对「为国聚财、为民收税」的理解？遇到纳税人不满怎么处理？ |
| 加分项 | 党员、公文写作、时政积累、基层服务意识、表达沉稳 |
| 技术岗（信息中心/数据中心） | 会问：数据库、网络安全、系统运维、数据分析；项目讲清即可 |

### 运营商（三大运营商）

| 维度 | 内容 |
|---|---|
| 流程 | 网申 → 笔试（行测+专业）→ 一面（半结构化）→ 二面（综合/领导面） |
| 面试风格 | 半结构化：技术面（科技岗）+ 综合面（职业规划/稳定性/服从分配） |
| 高频题 | 为什么选我们公司？能接受区县/轮岗吗？5G/云计算/AI 在通信行业的应用？ |
| 加分项 | 党员、属地、对运营商业务（云网融合、算力网络、智慧城市）有认知 |
| 技术岗 | AI 应用岗会问：大模型/RAG/Agent 落地场景；后端问 Java/Spring/数据库 |

### 央企（能源 / 粮食 / 电网类等）

| 维度 | 内容 |
|---|---|
| 流程 | 网申 → 笔试（行测+企业文化）→ 结构化/半结构化面试 |
| 面试风格 | 重政治素养、企业文化认同、稳定性；科技岗才深挖技术 |
| 高频题 | 对央企责任的理解？为什么不去互联网？能接受基层一线吗？ |
| 加分项 | 党员、对粮储/能源/电力行业背景有了解、能吃苦、服从安排 |
| 技术岗 | 信息化/数字化岗：系统建设、数据治理、网络安全、AI 赋能业务 |

## 银行

### 总行 / 省分行科技岗 / 城商行

| 维度 | 内容 |
|---|---|
| 流程 | 网申 → 笔试（行测+英语+计算机）→ 技术面 → 综合面/HR 面 |
| 面试风格 | 半结构化：技术（项目深挖、数据库、分布式、安全合规）+ 综合（抗压、合规意识、职业稳定性） |
| 高频题 | 为什么进银行？对银行科技岗的认识？加班/值班接受吗？数据安全怎么保证？ |
| 加分项 | 党员、对金融科技（支付/风控/反洗钱）有认知、表达稳重、能讲清一个完整项目 |
| 技术岗注意 | 银行重**合规与安全**：权限控制、数据隔离、审计日志——项目里的 Token 鉴权/数据隔离正好对应，重点准备 |

## 事业单位

| 维度 | 内容 |
|---|---|
| 流程 | 笔试（公基/职测）→ 结构化面试 → 体检政审 |
| 面试风格 | 结构化：时政理解、职业认知、组织协调、应急应变 |
| 高频题 | 对「为人民服务」的理解？领导交办急事你怎么安排？同事关系怎么处理？ |
| 加分项 | 党员、时政积累、公文写作、社会实践/学生干部经历 |

## 互联网大厂（精简保留）

> 若用户投互联网公司，用下表；字节的「算法必考」等特征只在明确投大厂时启用。

| 公司 | 面试重点 | 典型题 |
|---|---|---|
| 阿里 | 价值观对齐 + 系统设计 + 决策追问 | 为什么这么做而不是那么做？你哪里不够阿里？ |
| 腾讯 | 刨根问底底层原理（源码级） | TCP 为什么三次握手？Redis ZSet 底层？ |
| 字节 | 算法必考（LeetCode Medium+）+ 项目 Impact | LRU 缓存；最有成就感项目 + Impact 怎么衡量 |
| 百度 | 技术基础 + AI 岗论文/数学 | Transformer 为什么除根号 d_k？ |
| 美团 | 业务 sense + 工程效率 | 如何提高研发效率？ |
| 京东 | 供应链/物流系统 + Java 深度 | 高并发订单系统怎么设计？ |
| 滴滴/快手/小红书/拼多多 | 各按业务特色：地图调度/推荐/社区/执行力 | 见各自业务域 |

本 skill 面向国内求职（央国企/银行/事业单位/国内大厂），Google/Meta/Amazon/Microsoft 画像不展开。如用户明确要面外企，按需另行补充。

## 岗位类型速查

科技/后端岗 → 深挖项目与基础；业务/综合岗 → 结构化表达与动机；AI 应用岗 → 大模型/RAG/Agent 落地（见 `question-design.md` AI 题库）。
