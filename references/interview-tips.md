# Interview Tips: STAR Material, Reverse Questions, Roleplay

Read this reference when the user prepares interview talking points, wants reverse questions for the interviewer, or asks for roleplay interview practice. It complements `interview-method.md` (the question ladder and one-question protocol) with the speaking-material layer.

## STAR Format

Structure spoken answers as:

- **Situation** — context: what was happening, what problem existed.
- **Task** — the user's personal responsibility.
- **Action** — what the user actually did (specific tools, methods, decisions; this gets the most detail).
- **Result** — outcome with a source where possible; end with what they learned or would do differently.

Keep answers to 1–2 minutes. Be specific. Under interruption, the user should be able to finish the point in one breath and hand back the conversation.

## STAR Material Template

For each project prepared for interview, write a STAR card (this becomes the basis for the battle card's 1-minute version):

```markdown
### 项目名（体现的能力标签）
**S：** 背景——项目要解决什么问题，当时的处境
**T：** 我的职责——我具体负责哪一块
**A：** 我做了什么——动作、选型、解决的具体难点（最详细）
**R：** 结果——可验证的产出；学到什么 / 下次怎么做更好
**适用于：** "介绍你的项目"、"讲一个你解决的难题"、"你最大的挑战"
```

Prepare 4–6 such cards covering different competencies (technical depth, problem solving, collaboration, ownership, learning speed), and map each card to the question types it answers.

## Common Tough Questions

Prepare honest, forward-looking answers; never coach the user to speak negatively about a former employer or teammate:

- **离职原因 / 为什么换方向** — 真实动机 + 向前看，不贬低前东家。
- **“你没有 X 经验/技能”** — 承认差距，桥接到相邻经验，展示学习路径（有证据：已完成的课程、可运行的 demo）。
- **“你未来 3–5 年怎么规划”** — 与岗位成长路径对齐，不空谈。
- **“你最大的缺点”** — 真实弱点 + 具体改进措施，不玩“我太追求完美”的套路。
- **“为什么选我们公司”** — 必须具体：提到该公司的项目、产品、技术栈、团队或市场，禁止通用答案。

## Reverse Questions For The Interviewer

Offer these by category and let the user pick what fits:

- **岗位：** 这个角色一周的典型工作节奏？入职前 6 个月的成功标准？团队当前最大的挑战？
- **团队：** 团队规模和分工方式？从想法到上线的流程？新人的 onboarding 方式？
- **技术与成长：** 当前技术栈？有没有机会参与架构级决策？团队怎么跟进新技术？
- **文化：** 团队文化怎么形容？专业发展路径？开发新项目与维护的比例？什么样的同事在这里成长最好？

## Roleplay Guidelines

When the user asks for mock interview practice:

1. **Follow the one-question protocol** from `interview-method.md`: ask exactly one question, wait, then assess + reference answer + one next move.
2. Start with a warm-up ("先介绍一下你自己 / 这个项目是做什么的"), then move to role-specific technical questions grounded in the project, include 1–2 behavioral questions, and end with a harder or unexpected question.
3. After each answer, give brief feedback: what was concrete, what was missing, and which STAR card would have served better.
4. If the user is visibly stuck, give one small hint and stay at the same depth; do not hand over the full answer.
5. Keep the tone conversational. Vary question phrasing so the user does not memorize a script.

## Phone / Video Interview Tips

- Keep STAR cards visible and written out (use the battle card).
- Ask for clarification if a question is vague; it is fine to take 5 seconds to think.
- End answers with a natural hand-back ("这块如果要展开，我可以再讲某个具体场景").
- Close with something like: "您还有什么想进一步了解的背景吗？"
